## 🌶️ What is this?
**Biryani Ipsum** is a fun, open-source tool for developers and designers. Instead of the standard *"Lorem ipsum dolor sit amet"*, this tool generates spicy, aromatic text using vocabulary from India's most beloved dish.

Perfect for:
* **Food Blogs & Restaurant Websites**
* **Mockups that need flavor**
* **Developers tired of boring text**

## ✨ Features
* **Customizable Servings:** Choose between Small (Snack), Medium (Lunch), or Large (Feast) paragraphs.
* **Spiciness Control:** Toggle `<p>` tags or start with the classic "Biryani ipsum..." phrase.
* **One-Click Copy:** Instantly copy text to your clipboard.
* **Lightweight:** Built with vanilla HTML, JS, and Tailwind CSS. No heavy frameworks.
* **Responsive:** Looks delicious on mobile and desktop.

## 🚀 Usage

### Option 1: Use the Website
Just visit the [Live Site](https://sharvnaik.github.io/biryani-ipsum/) and start generating.
